Wi-Fi setup by sound

A phone tells a device which Wi-Fi to join, by sound. The right half of this page plays the device, so you can test with two tabs (or with the loopback button, no audio). The real device is the ESP32 in ../esp32-wifi-setup (planned).

Sound is not secret. Anyone within earshot of the speaker (and anything that records it) can decode the message. Sending a password in the clear means everyone nearby learns it. Use the protected mode below, or only send to a device that is not a stranger's.

    What the protection does, honestly

    • The credentials are encrypted (AES-GCM) with a key derived from an 8-character code (about 40 bits) that only the device screen shows. Someone who hears the sound but cannot see the screen sees ciphertext.
    • The code is one-time and valid for 2 minutes: after one successful use, or when it expires, the device refuses further messages with it.
    • It does not stop a determined attacker who recorded the sound: 40 bits can be guessed offline given enough hardware (PBKDF2 only slows it down). It also does not authenticate the device to the phone. For anything valuable use a longer code or a real pairing protocol.
    • Needs a secure context for crypto.subtle (https or localhost).
